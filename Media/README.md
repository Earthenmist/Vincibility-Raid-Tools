# Visual-note circle texture

`circle256.tga` is VRT's own filled-circle texture for the visual-note Filled circle tool: a 256×256 white disc with an anti-aliased edge (8×8 supersampled), stored as a 32-bit RLE TGA and tinted in game. It was generated for VRT; no third-party art is used.

The `Ring*.png` textures used by circle reminders were also generated for VRT.
