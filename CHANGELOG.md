# Vincibility Raid Tools 1.0.1-Release

Hotfix for 1.0.0-Release.

## Changes

- Updated for patch 12.1.5; 12.1.0 is no longer listed.

## Fixes

- **Auras:** the raid debuff overview no longer goes blank on every boss after 12.1.5. A spell list added to one boss now applies only in that boss's fight; other fights use the Every boss list, or all boss and dispellable debuffs when it is empty. The same applies to co-tank debuffs. Lists switch when you enter the boss area or leave combat.

## Known issues

- Per-boss lists for The Venomous Abyss apply on Heroic with an English client (Kith'ix in any language); elsewhere the Every boss list applies.
- Still awaiting in-game confirmation: BigWigs-only and no-boss-mod setups.
